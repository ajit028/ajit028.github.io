## 🚀 1-Minute GitHub Pages Deployment Guide

Follow these simple steps to host this portfolio live on your GitHub:

### Option A: Create `ajit028.github.io` (Recommended for personal root portfolio)

1. Create a new repository on GitHub named **`ajit028.github.io`** (replace with your GitHub username).
2. Open your terminal in this folder (`C:/Users/ajitn/portfolio`) and run:

```bash
# Initialize git
git init
git add .
git commit -m "feat: Initial deployment of futuristic SOC cybersecurity portfolio"

# Rename branch to main
git branch -M main

# Link to your remote GitHub repository
git remote add origin https://github.com/ajit028/ajit028.github.io.git

# Push to GitHub
git push -u origin main
```

3. Within ~60 seconds, your portfolio will be live at:
👉 **`https://ajit028.github.io/`**

---

### Option B: Host in a repository named `portfolio`

1. Create a repository on GitHub named **`portfolio`**.
2. Run:

```bash
git init
git add .
git commit -m "feat: Deploy futuristic SOC cybersecurity portfolio"
git branch -M main
git remote add origin https://github.com/ajit028/portfolio.git
git push -u origin main
```

3. In GitHub: Go to **Settings** → **Pages** → Under **Branch**, select `main` and `/ (root)` → Click **Save**.
4. Your portfolio will be live at:
👉 **`https://ajit028.github.io/portfolio/`**
